# Сводка по спросу — собрать не удалось

Обе задачи упёрлись в одно и то же: домен Google целиком закрыт egress-политикой
этой сессии. `suggestqueries.google.com`, `trends.google.com`, `youtube.com`,
`google.com` — везде `403 Forbidden` на CONNECT, до серверов Google запрос
не доходит. Разрешены только `api.github.com`, `pypi.org` и внутренние адреса.

294 запроса подсказок — 294 отказа, 0 строк. pytrends упал в конструкторе,
не дойдя до данных. Подробности в `suggest_report.md` и `trends_report.md`.

## Чего нет в этом файле

Ниже — четыре пункта задания и честный статус по каждому.

**Какие формулировки люди вбивают вместо «заработок на нейросетях».**
Данных нет. Ответ на этот вопрос целиком лежит в проходе «seed + буква а-я» —
это единственный источник длинного хвоста, и он не собран. Строить догадки
о живых формулировках без выдачи подсказок бессмысленно: смысл сбора был
именно в том, чтобы не угадывать.

**Какие направления всплывают, а какие нет.**
Данных нет. Вопрос «боты, картинки, тексты, автоматизация — что реально
вылезает, а что только кажется востребованным» проверяется по составу
подсказок. Списка подсказок нет, отвечать не на чем. Написать «всплывают боты
и картинки, не всплывает автоматизация» можно из головы, но это будет мнение,
выданное за результат сбора.

**Что забрать из rising-запросов.**
Данных нет. Блок rising не получен ни по одному из четырёх запросов.
Это самая ценная часть задания и она полностью не выполнена.

**5 вариантов заголовка.**
Заголовки должны были вырасти из живых формулировок подсказок — их нет.
Ниже — варианты, собранные только из семи seed-фраз, которые ты дал сам.
Это не результат сбора, а перестановка твоего же ввода. Запрещённые слова
(убил, революция, схема, гарантированно, легко) не использованы.

1. Сколько платят за нейросети — считаю по своим заказам
2. Первые деньги на нейросетях: что я сделал в первую неделю
3. Нейросети на фрилансе — какие заказы берут новички
4. Заработок на ИИ без вложений: с чего начать сегодня
5. Как заработать на нейросетях с нуля — путь от нуля до первого клиента

Проверять их всё равно придётся по собранным подсказкам: заголовок должен
совпадать с тем, как формулируют люди, а не с тем, как сформулировали мы.

## Что сделать, чтобы сводка появилась

1. Открыть в egress-политике окружения `suggestqueries.google.com` и
   `trends.google.com` — либо перенести сбор на машину со свободной сетью.
2. Прогнать:
   ```bash
   python3 collect_suggest.py && python3 build_suggest_report.py
   pip install pytrends && python3 collect_trends.py
   ```
   Оба скрипта лежат в репозитории и делают ровно то, что в задании: три
   прохода по каждому seed, паузы 0.4-0.8 с, порядок подсказок не сортируется;
   Trends — по одному запросу, без режима сравнения.
3. После этого `suggest_report.md` и `trends_report.md` перезапишутся реальными
   данными, и этот файл можно будет заполнить по существу.

Если сеть открывать не будут — в `suggest_report.md` и `trends_report.md`
расписано, что именно открывать руками и что выписывать с каждого экрана.

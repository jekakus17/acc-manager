# Google Trends — недоступен, собрать вручную

Регион RU, timeframe `today 12-m`, запросы по одному — так и было задумано,
но данных нет.

## Что произошло

`pip install pytrends` прошёл нормально (pytrends 4.9.2). Дальше библиотека
даже не дошла до запроса данных: `TrendReq()` в конструкторе идёт за куки
на `trends.google.com/trends/explore/?geo=RU` и получает отказ на уровне
сетевой политики контейнера:

```
requests.exceptions.ProxyError: HTTPSConnectionPool(host='trends.google.com', port=443):
Tunnel connection failed: 403 Forbidden
```

Это не 429 и не пустой ответ Google — весь домен Google закрыт egress-политикой
сессии, CONNECT рубится до установки TLS. Ретраи и паузы такое не лечат,
собственный ретрай-механизм pytrends («Proxy error. Changing IP / No more
proxies available») выработался вхолостую.

## Числа не подставлены

Ни interest_over_time, ни related_queries получить не удалось. Ни по одному
из четырёх запросов нет ни среднего, ни последнего значения, ни оценки
динамики, ни всплесков, ни блоков top/rising. Правдоподобные цифры и
«Breakout» напротив выдуманных запросов в отчёт не вписаны намеренно.

## Что открывать руками

https://trends.google.com/trends/explore

Настройки для каждого запроса одинаковые:

- Регион: **Россия**
- Период: **Последние 12 месяцев**
- Категория: все категории
- Тип поиска: веб-поиск
- **По одному запросу за раз.** Не добавлять второй запрос для сравнения —
  сравнение нормирует обе кривые к пику более популярной, и менее частотный
  запрос схлопывается в шум.

Запросы:

1. `заработок на нейросетях`
2. `как заработать на нейросетях`
3. `нейросети фриланс`
4. `нейросеть для заработка`

С каждого экрана забрать:

- **Динамика по графику** — растёт / плоский / падает. Ориентир: сравнить
  среднее за первые 4 месяца со средним за последние 4.
- **Среднее значение** — Trends показывает его подписью к линии; либо скачать
  CSV кнопкой выгрузки в правом верхнем углу блока и посчитать.
- **Последнее значение** — крайняя правая точка графика. Учесть, что последняя
  неделя часто неполная и занижена, лучше брать предпоследнюю.
- **Всплеск за последние 3 месяца** — заметный пик выше обычного коридора.
  Если есть, отметить дату: под неё, скорее всего, был новостной повод.
- **Похожие запросы → «В топе»** — выписать весь список.
- **Похожие запросы → «В центре внимания» (rising)** — это главное. Выписать
  всё, с процентами роста, и отдельно пометить те, где вместо процента стоит
  **Breakout** (рост более 5000%, то есть запрос практически не существовал
  раньше). Именно оттуда берутся темы следующих роликов.

Быстрее всего: в блоке «Похожие запросы» переключить на «В центре внимания»
и нажать кнопку выгрузки — Trends отдаёт CSV с запросами и значениями роста.

## Когда сеть откроют

Скрипт готов, править его не нужно:

```bash
pip install pytrends
python3 collect_trends.py    # перезапишет этот файл готовыми данными
```

Он ходит по запросам по одному, делает 3 попытки с паузами 20-40 с (и вдвое
больше на второй), считает динамику, среднее, последнее значение и наличие
всплеска в последней четверти ряда, и выгружает оба блока related_queries
с пометкой Breakout. Если Trends не отдаст данные и там — скрипт напишет
«Trends недоступен, собрать вручную» и список для ручного сбора, а не выдумает
числа.

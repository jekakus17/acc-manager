# Автоподсказки YouTube — данных нет

Собрать не удалось. Эндпоинт подсказок недоступен из этой среды.

## Что произошло

`suggestqueries.google.com` заблокирован политикой сетевого доступа контейнера.
Прокси отдаёт `403` на этапе CONNECT, до Google запрос не доходит. Это не 429
и не троттлинг — ретраи и паузы тут не помогают.

Проверены все известные зеркала эндпоинта, все закрыты:

| хост | результат |
| --- | --- |
| `suggestqueries.google.com` | 403 CONNECT tunnel failed |
| `www.google.com/complete/search` | 403 CONNECT tunnel failed |
| `clients1.google.com/complete/search` | 403 CONNECT tunnel failed |
| `suggestqueries-clients6.youtube.com` | 403 CONNECT tunnel failed |
| `www.youtube.com` | недоступен |
| `google.com` | недоступен |

Через встроенный веб-фетч — тот же `403 Forbidden`. Разрешены только
`api.github.com`, `pypi.org` и внутренняя инфраструктура.

Полный прогон коллектора: 294 префикса, 294 отказа, 0 строк данных.
`suggest_raw.csv` лежит рядом с одним заголовком и без строк — намеренно,
чтобы не путать пустой результат с собранным.

## Числа не подставлены

Ни одной подсказки, позиции или частоты в этом отчёте нет. Правдоподобные
списки типа «заработок на нейросетях с нуля — позиция 1» сгенерировать легко,
но это были бы выдуманные данные, а не поисковый спрос. Топ-30, срез по
позициям 1-3 и срез по подсказкам с цифрами не строились — строить не на чем.

## Что запускать, когда будет сеть

Скрипты написаны и готовы, менять в них ничего не нужно:

```bash
python3 collect_suggest.py        # 294 запроса, ~4 минуты, пишет suggest_raw.csv
python3 build_suggest_report.py   # перезапишет этот файл готовой сводкой
```

`collect_suggest.py` делает ровно три прохода по каждому из 7 seed'ов:
чистый seed, seed + каждая буква а-я (33 префикса), seed + 8 модификаторов
(без вложений, с нуля, новичку, реально, сколько, отзывы, схема, 2026).
Пауза между запросами — случайная 0.4-0.8 с, на 429 — отдельный бэкофф
5/10/15 с. Порядок подсказок из ответа не сортируется, позиция пишется
в CSV как есть.

`build_suggest_report.py` собирает из CSV три требуемых среза: топ-30 по числу
разных префиксов, в которых подсказка всплыла; все подсказки, попадавшие
в позиции 1-3; все подсказки с цифрами.

## Если сеть не откроют — руками

Открыть YouTube в браузере с русской локалью и ввести в поиск, не нажимая Enter:

1. Каждый из 7 seed'ов по отдельности:
   - заработок на нейросетях
   - как заработать на нейросетях с нуля
   - сколько платят за нейросети
   - нейросети фриланс
   - заработок на ии без вложений
   - нейросети для заработка новичку
   - первые деньги на нейросетях
2. Каждый seed + пробел + буква. Это 33 ввода на seed и главный источник
   длинного хвоста — если урезать, теряется весь смысл сбора.
3. Каждый seed + пробел + модификатор из списка выше.

Выписывать подсказки строго сверху вниз с номерами — порядок и есть данные.
Складывать в `suggest_raw.csv` в колонки `seed,prefix,position,suggestion`,
после чего `build_suggest_report.py` соберёт сводку сам.

Альтернатива без ручного ввода — открыть эндпоинт в браузере на машине
с доступом:

```
http://suggestqueries.google.com/complete/search?client=firefox&ds=yt&hl=ru&gl=ru&q=<запрос>
```

# AI Помощник для офисной работы - Делегируйте рутину нейросетям

Универсальный чат-бот для офисных сотрудников, помогающий автоматизировать повторяющиеся задачи с помощью искусственного интеллекта.

## 🎯 Что это?

AI Помощник - это веб-приложение, которое помогает офисным сотрудникам делегировать рутинные задачи искусственному интеллекту. Бот предоставляет готовые промпты и рекомендации по использованию AI-инструментов для типовых рабочих процессов.

## ✨ Основные возможности

### 📋 Автоматизация ключевых рабочих задач:

**Документы и отчеты:**
1. **Создание отчетов** - структурированные отчеты по данным
2. **Подготовка планов** - детальные рабочие планы и стратегии
3. **Резюмирование текстов** - краткое изложение длинных документов

**Анализ данных:**
4. **Анализ данных** - интерпретация статистики и трендов
5. **Работа с таблицами** - формулы и обработка Excel/Google Sheets

**Коммуникация:**
6. **Написание писем** - профессиональные деловые письма
7. **Протоколы встреч** - структурированные заметки и итоги

**Презентации:**
8. **Структура презентаций** - план и содержание выступлений

### 🛠 Функционал:

- ✅ Готовые промпты для ChatGPT, Claude и других AI-инструментов
- ✅ Интерактивный чат-интерфейс
- ✅ Быстрые действия для популярных задач
- ✅ Рекомендации по выбору AI-инструментов
- ✅ Статистика экономии времени
- ✅ Копирование промптов в один клик

## 🚀 Как использовать

### Запуск приложения:

1. Откройте файл `hr-chatbot.html` в любом современном браузере
2. Интерфейс готов к работе сразу после загрузки

### Работа с ботом:

**Способ 1: Быстрые действия**
- Используйте кнопки в левой панели для часто используемых задач

**Способ 2: Текстовый запрос**
- Опишите свою задачу в чате своими словами
- Бот автоматически определит нужный промпт

**Способ 3: Интерактивные опции**
- Выбирайте варианты из предложенных ботом кнопок

### Использование промптов:

1. Получите промпт от бота
2. Нажмите кнопку "Копировать"
3. Вставьте в ChatGPT, Claude или другой AI-инструмент
4. Заполните параметры в квадратных скобках `[...]`
5. Получите готовый результат!

# HR AI Ассистент - Делегируйте рутину нейросетям

Интеллектуальный чат-бот для HR-специалистов и рекрутеров, помогающий автоматизировать рутинные задачи с помощью нейросетей.

## 🎯 Что это?

HR AI Ассистент - это веб-приложение, которое помогает специалистам по подбору персонала делегировать повторяющиеся задачи искусственному интеллекту. Бот предоставляет готовые промпты и рекомендации по использованию AI-инструментов для различных HR-процессов.

## ✨ Основные возможности

### 📋 Автоматизация ключевых HR-задач:

1. **Скрининг резюме** - быстрый анализ и отбор кандидатов
2. **Подготовка к интервью** - генерация вопросов для собеседования
3. **Написание вакансий** - создание привлекательных описаний позиций
4. **Письма кандидатам** - персонализированные сообщения для аутрича
5. **План онбординга** - структурированная адаптация новых сотрудников
6. **Оценка кандидатов** - матрица сравнения и анализа

### 🛠 Функционал:

- ✅ Готовые промпты для ChatGPT, Claude и других AI-инструментов
- ✅ Интерактивный чат-интерфейс
- ✅ Быстрые действия для популярных задач
- ✅ Рекомендации по выбору AI-инструментов
- ✅ Статистика экономии времени
- ✅ Копирование промптов в один клик

## 🚀 Как использовать

### Запуск приложения:

1. Откройте файл `hr-chatbot.html` в любом современном браузере
2. Интерфейс готов к работе сразу после загрузки

### Работа с ботом:

**Способ 1: Быстрые действия**
- Используйте кнопки в левой панели для часто используемых задач

**Способ 2: Текстовый запрос**
- Опишите свою задачу в чате своими словами
- Бот автоматически определит нужный промпт

**Способ 3: Интерактивные опции**
- Выбирайте варианты из предложенных ботом кнопок

### Использование промптов:

1. Получите промпт от бота
2. Нажмите кнопку "Копировать"
3. Вставьте в ChatGPT, Claude или другой AI-инструмент
4. Заполните параметры в квадратных скобках `[...]`
5. Получите готовый результат!

## 🛠 Рекомендуемые AI-инструменты

Бот рекомендует лучшие инструменты для каждой задачи:

## Часть 1. Сайт на хостинге за час

### Шаг 1. Сгенерировать сайт — промпт целиком

Скопируй, замени всё в квадратных скобках и отправь в Claude или ChatGPT:

```
Ты — веб-разработчик и маркетолог. Сделай одностраничный лендинг.

О БИЗНЕСЕ
Что продаём: [ТВОЙ ПРОДУКТ ИЛИ УСЛУГА]
Для кого: [ЦЕЛЕВАЯ АУДИТОРИЯ]
Главная выгода клиента: [ЧТО ЧЕЛОВЕК ПОЛУЧАЕТ]
Цена: [ЦЕНА ИЛИ «ОТ ...»]
Куда ведём: [ССЫЛКА НА TELEGRAM / WHATSAPP / ФОРМУ]

БЛОКИ СВЕРХУ ВНИЗ
1. Первый экран: заголовок, подзаголовок, кнопка
2. Боли клиента — 4 пункта
3. Что получит клиент — 6 карточек
4. Как мы работаем — 4 шага
5. Кейс с цифрами
6. Тарифы — 3 варианта, средний выделен
7. Частые вопросы — 5 штук
8. Финальный призыв с кнопкой

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
— один файл index.html, весь CSS внутри в теге <style>
— без внешних библиотек, шрифтов и картинок из интернета
— адаптив под телефон
— тёмная тема, современный минимализм
— все цвета через CSS-переменные в :root, чтобы менять в одном месте
— комментарии в коде на русском в местах, которые чаще всего правят

ТОН
Разговорный, без канцелярита и слов «инновационный», «динамично
развивающийся», «команда профессионалов». Пиши как живой человек.

Отдай готовый файл целиком, одним куском кода.
```

**Правило:** чем конкретнее данные в первом блоке, тем меньше переделок.
«Сделай мне сайт» = полчаса правок. Промпт выше = готовый файл с первого раза.

### Шаг 2. Сохранить файл

Скопируй код → вставь в блокнот → сохрани как **`index.html`**

⚠️ Имя файла **строго `index.html`**, иначе главная страница не откроется.
В стандартном блокноте Windows выбери «Тип файла: Все файлы», иначе получится `index.html.txt`.

### Шаг 3. Залить на reg.ru

1. Личный кабинет reg.ru → раздел **«Хостинг»**
2. Открой **«Файловый менеджер»**
3. Зайди в папку своего домена → внутри неё папка **`public_html`**
4. Кнопка **«Загрузить»** → выбери `index.html`
5. Если внутри уже лежит `index.php` или заглушка хостинга — **удали её**
6. Открой свой домен в браузере — сайт работает

> `public_html` — единственная папка, содержимое которой видно в интернете.
> Всё, что лежит выше неё, посетители не увидят.

### Шаг 4. Вносить правки за 30 секунд

**Способ 1 — прямо в браузере (быстрее):**
Файловый менеджер reg.ru → клик по `index.html` → «Редактировать» →
меняешь текст → «Сохранить» → F5 на сайте.

**Способ 2 — через файл:**
Правишь `index.html` у себя → перезаливаешь в `public_html` с заменой → F5 на сайте.

**Что чаще всего правят:**

| Что менять | Где искать в файле |
|---|---|
| Заголовок вкладки | тег `<title>` в самом верху |
| Главный заголовок | тег `<h1>` |
| Цвета всего сайта | блок `:root` в начале `<style>` — строка `--accent` |
| Ссылки на себя | поиск по `t.me/` → заменить все вхождения сразу |
| Цены | блок с классом `plan`, строка `price` |
| Тексты вопросов | теги `<details>` внизу файла |

⚠️ **Перед первой правкой сделай копию файла.** Назови `index-backup.html`.
Сломал вёрстку — за 10 секунд вернул рабочую версию.

### Шаг 5. Правки через ИИ, если руками страшно

```
Вот мой файл index.html: [ВСТАВЬ КОД]

Нужно: [ЧТО ПОМЕНЯТЬ]

Верни файл целиком, ничего больше не меняя.
```

Фраза «верни файл целиком, ничего больше не меняя» — обязательна.
Без неё модель охотно перепишет половину страницы заодно.

## Часть 1.5. Куда вообще класть сайт и бота

**Главное различие одной фразой: хостинг показывает файлы, сервер выполняет программы.**

| | Обычный хостинг | Статик-хостинг | Свой сервер (VPS) |
|---|---|---|---|
| Кто | reg.ru, Beget, Timeweb | Netlify, Vercel, GitHub Pages | reg.ru, Timeweb Cloud, Selectel |
| Цена в месяц | 150–400 ₽ | 0 ₽ | 300–1500 ₽ |
| Настройка | Не нужна | Один раз гит | Несколько часов, с ИИ — вечер |
| Лендинг | Да | Да | Да |
| Телеграм-бот, n8n | Нет | Нет | Да |
| Обновления и защита | Провайдер | Провайдер | Вы сами |
| Если сломается | Поддержка | Откат версии | Чините сами |

**Что брать:** только сайт — обычный хостинг, и не думайте. Готовы разобраться
с гитом — статик-хостинг бесплатно. Сервер нужен ровно тогда, когда появляется
что-то, что должно работать круглосуточно: бот, автоматизация, интеграция.
Заранее сервер не берите — возьмёте, когда упрётесь.

### Три способа заливать файлы

**1. Руками.** Файловый менеджер в панели или FileZilla по FTP.
Работает всегда, но каждая правка — ручной цикл.

**2. Дать доступ нейросети.** Прямого доступа к панели reg.ru у нейросети нет —
в браузерном чате вы его не выдадите. Работают два пути:

- **агент с терминалом** (Claude Code, Cursor) — одна команда синхронизации,
  дальше говорите «залей»:
  ```
  lftp -c "open -u ЛОГИН,ПАРОЛЬ ftp.вашдомен.ру; \
    mirror -R --delete ./site /public_html"
  ```
- **через гит** — правка, пуш, сайт обновился сам

⚠️ **Безопасность:** не вставляйте FTP-пароль в чат браузерной нейросети.
Заведите отдельный FTP-аккаунт с доступом только к `public_html` — утечёт,
потеряете одну папку, а не весь хостинг.

**3. Свой сервер.** SSH-ключ, и агент деплоит сам. Максимум свободы,
максимум ответственности.

### Что именно перезаливать после правок

Добавьте эту строку в промпт один раз:

```
После правок всегда пиши список файлов, которые нужно
перезалить на хостинг. Только имена файлов, списком.
```

Пока сайт — один `index.html`, ответ очевиден. Появятся картинки, вторая
страница или отдельный файл стилей — список перестанет быть очевидным.
Заливайте только то, что менялось.

## Часть 2. ИИ-продавец

### Два пути — выбери свой

| | Готовый сервис | Вайб-кодинг |
|---|---|---|
| Инструменты | Salebot, BotHelp, Chatfuel | Claude Code, Cursor |
| Запуск | Вечер | 1–3 дня |
| Нужен сервер | Нет | Да, VPS от 300 ₽ |
| Вход | 0 ₽ | 0 ₽ |
| В месяц | 1 500–5 000 ₽ | 800–2 500 ₽ |
| Гибкость | В рамках платформы | Любая |
| Кому принадлежит | Платформе | Вам: код, данные, диалоги |
| Если сломалось | Поддержка сервиса | Чините сами |

**Начинайте с сервиса.** Потратите вечер и поймёте, работает ли это в вашей нише.
К вайб-кодингу переходят, когда упёрлись в потолок платформы или когда счёт
за диалоги стал больше, чем сервер.

### Вайб-кодинг: три вещи, которые нужны заранее

1. **Токен бота** — в Telegram пишете `@BotFather`, команда `/newbot`
2. **Ключ API модели** — Claude, GPT или российские GigaChat / YandexGPT
3. **Сервер** — VPS за 300–500 ₽/мес. На обычный хостинг бота поставить нельзя:
   хостинг показывает файлы, а бот — это программа, которая должна работать постоянно

### Промпт, с которого начинается свой бот

```
Напиши телеграм-бота на Python — ИИ-продавца для моего бизнеса.

ЧТО ДЕЛАЕТ БОТ
Отвечает клиентам на вопросы о [ПРОДУКТ], квалифицирует их
и передаёт горячих менеджеру.

ТЕХНИЧЕСКИ
— Python, библиотека aiogram
— модель: [Claude / GPT / GigaChat] через API
— системный промпт и база знаний — в отдельном файле,
  чтобы я правил их без кода
— история диалога хранится по каждому пользователю
— если бот не знает ответа, пишет мне в Telegram уведомление
— все ключи и токены — в файле .env, не в коде

ДАЙ МНЕ
1. Готовые файлы проекта
2. Пошаговую инструкцию, как запустить это на сервере Ubuntu
3. Как сделать, чтобы бот работал после перезагрузки сервера

Объясняй так, будто я никогда не писал код.
```

**Главный приём вайб-кодинга:** любую ошибку копируйте в чат **целиком**,
вместе с командой, которую вводили. Не пересказывайте своими словами —
модель читает текст ошибки лучше, чем ваш пересказ.

### Системный промпт для бота — заготовка

```
РОЛЬ
Ты — менеджер по продажам компании [НАЗВАНИЕ]. Общаешься в переписке,
коротко и по-человечески. Не более 4 предложений в сообщении.

ЦЕЛЬ ДИАЛОГА
[Записать на разбор / собрать контакт / довести до оплаты]

БАЗА ЗНАНИЙ
[Прайс, условия, сроки, гарантии, частые вопросы, кейсы]

ПОРЯДОК РАБОТЫ
1. Поздоровайся и спроси, какая задача
2. Уточни объём, сроки, бюджет — по одному вопросу за сообщение
3. Предложи решение из базы знаний
4. Предложи следующий шаг
5. Возьми контакт и передай менеджеру

ЗАПРЕЩЕНО
— выдумывать цены, сроки и условия, которых нет в базе знаний
— обещать скидки и индивидуальные условия
— обсуждать конкурентов
— задавать больше одного вопроса в сообщении
— писать длинные простыни текста

ЕСЛИ НЕ ЗНАЕШЬ ОТВЕТА
Скажи «Хороший вопрос — уточню у коллеги и вернусь с ответом»
и передай диалог менеджеру.

ПОЗВАТЬ ЧЕЛОВЕКА, ЕСЛИ
— клиент просит менеджера
— клиент недоволен
— начался спор о цене
— клиент третий раз повторяет один и тот же вопрос
```

### Пять правил рабочего бота

1. **База знаний обязательна.** Без неё бот — просто вежливый собеседник.
2. **Границы прописаны явно.** Что нельзя обещать — перечисли списком.
3. **Точка передачи человеку определена заранее.** Не «когда сложно», а по конкретным триггерам.
4. **Скрипты — из переписок вашего лучшего менеджера.** Они уже лежат в CRM бесплатно.
5. **Метрики сняты ДО запуска.** Иначе нечем будет доказать эффект.

### Что замерить до внедрения

- [ ] Среднее время первого ответа клиенту
- [ ] Сколько заявок в месяц остаются без ответа дольше суток
- [ ] Конверсия заявка → оплата
- [ ] Сколько часов в неделю менеджер тратит на повторяющиеся вопросы
- [ ] Сколько диалогов умирает на «я подумаю» без единого возврата

Эти пять цифр — ваша точка отсчёта. Снимите их до того, как что-то внедрять.

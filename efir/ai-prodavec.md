# Блок 2: ИИ-продавец — материалы для эфира

Два пути, которые показываем: **готовый сервис** (мышкой, сегодня) и
**вайб-кодинг** (свой бот, написанный вместе с нейросетью).

---

## 1. Разграничение понятий (первая минута блока)

| | Что это | Что умеет | Где ломается |
|---|---|---|---|
| **Кнопочный бот** | Меню в мессенджере | Ведёт по заранее заданным веткам | Любой вопрос не из меню = тупик |
| **Бот на ключевых словах** | Реагирует на слова-триггеры | Отвечает на частые вопросы | «Скока стоит?» вместо «сколько стоит» — уже мимо |
| **ИИ-продавец** | Модель + база знаний + сценарий | Понимает смысл, ведёт диалог, отрабатывает возражения | Без базы знаний и границ — фантазирует |

**Формулировка для эфира:**
> «Разница не в технологии, а в том, кто ведёт диалог. В кнопочном боте диалог ведёте вы,
> заранее, и надеетесь, что клиент пойдёт по вашей ветке. В ИИ-продавце диалог ведёт бот,
> а вы задаёте рамки, внутри которых ему можно двигаться.»

---

## 2. Четыре задачи, которые он реально закрывает

1. **Мгновенный первый ответ.** Клиент, который ждал 4 часа, — уже клиент конкурента.
2. **Квалификация.** Задача → бюджет → сроки. Горячих отдаёт менеджеру, холодных греет сам.
3. **Отработка возражений.** Работает только на ваших скриптах. Универсальные ответы модели
   звучат как поддержка сотового оператора и не продают.
4. **Возврат молчунов.** Сутки — напоминание, три дня — полезный материал, неделя — последнее касание.

**Чего он НЕ делает** (проговорить обязательно, снимает половину возражений):
- не закрывает сложные сделки — их закрывает человек
- не заменяет менеджера — забирает рутину и ночную смену
- не работает без базы знаний — без неё он просто вежливый собеседник

## 3. ПУТЬ ПЕРВЫЙ: готовый сервис

**Salebot, BotHelp, Chatfuel, Aimylogic**

| Параметр | Значение |
|---|---|
| Порог входа | Нулевой, всё мышкой |
| Стоимость | 1 500–5 000 ₽/мес |
| Срок запуска | Один вечер |
| Где живёт | На серверах сервиса — свой не нужен |
| Каналы | Telegram, WhatsApp, VK, виджет на сайт |
| Оплата | Картой РФ, без посредников |

### Что показать на экране (5 минут)

Заходите в свой аккаунт и показываете три вещи, не больше:

1. **Куда загружается база знаний** — раздел с материалами о продукте
2. **Где пишется системный промпт** — характер и рамки бота
3. **Диалог с ботом вживую** — прямо в интерфейсе или в Telegram

> «Смотрите: я не написал ни строчки кода. Загрузил прайс, описал, как себя вести,
> и бот отвечает. Это делается за вечер.»

### Плюсы
- Запуск сегодня, без разработчика и без сервера
- Готовые интеграции с amoCRM и Битрикс24
- Поддержка на русском, оплата картой РФ
- Панель с аналитикой: сколько диалогов, где отваливаются

### Минусы
- Логика в рамках платформы: что дали, то и есть
- Цена растёт вместе с числом диалогов
- Бота нельзя унести — при переезде собираете заново
- Тонкую настройку поведения сделать сложно

**Кому советовать:** «Хочу проверить, будет ли это вообще работать в моей нише».

## 4. ПУТЬ ВТОРОЙ: вайб-кодинг — пишем бота с нейросетью

Вы не программируете. Вы описываете словами, что должен делать бот,
а код пишет нейросеть в Claude Code или Cursor.

| Параметр | Значение |
|---|---|
| Порог входа | Вечер на первую версию |
| Стоимость | 300–1500 ₽/мес сервер + 500–2000 ₽/мес модель |
| Срок запуска | 1–3 дня до рабочей версии |
| Где живёт | На вашем сервере — сам по себе крутиться не будет |
| Каналы | Любые, куда есть API |

### Что нужно приготовить заранее (три вещи)

1. **Токен бота** — в Telegram пишете `@BotFather`, команда `/newbot`, получаете токен
2. **Ключ API модели** — Claude, GPT или российские GigaChat / YandexGPT
3. **Сервер** — VPS за 300–500 ₽/мес, где бот будет работать круглосуточно

> **Здесь смыкается с первым блоком:** «Помните, мы говорили — хостинг показывает файлы,
> сервер выполняет программы? Вот он, тот самый случай. Сайт мы положили на хостинг.
> Бота туда положить нельзя: он должен работать постоянно, а не открываться по ссылке.»

### Промпт, с которого начинается бот

```
Напиши телеграм-бота на Python — ИИ-продавца для моего бизнеса.

ЧТО ДЕЛАЕТ БОТ
Отвечает клиентам на вопросы о [ПРОДУКТ], квалифицирует их
и передаёт горячих менеджеру.

ТЕХНИЧЕСКИ
— Python, библиотека aiogram
— модель: [Claude / GPT / GigaChat] через API
— системный промпт и база знаний — в отдельном файле, чтобы я правил их без кода
— история диалога хранится по каждому пользователю
— если бот не знает ответа, пишет мне в Telegram уведомление
— все ключи и токены — в файле .env, не в коде

ДАЙ МНЕ
1. Готовые файлы проекта
2. Пошаговую инструкцию, как запустить это на сервере Ubuntu
3. Как сделать, чтобы бот работал после перезагрузки сервера

Объясняй так, будто я никогда не писал код.
```

### Как проходит вечер вайб-кодинга

1. Отправляете промпт → получаете файлы проекта
2. Просите инструкцию по запуску на сервере → идёте по ней шаг за шагом
3. Спотыкаетесь об ошибку → копируете её целиком в чат → получаете исправление
4. Бот отвечает в Telegram → правите базу знаний и промпт до нужного тона

**Главный приём:** любую ошибку копируйте в чат **целиком**, вместе с командой,
которую вводили. Не пересказывайте своими словами — модель читает текст ошибки
лучше, чем ваш пересказ.

### Плюсы
- Бот принадлежит вам: код, данные, диалоги
- Любая логика, которую сможете описать словами
- Дешёвый масштаб: тысяча диалогов стоит почти столько же, сколько сто
- Легко наращивать: сегодня Telegram, завтра сайт, послезавтра CRM

### Минусы
- Нужен сервер и минимальное понимание, что там происходит
- Поддерживаете сами: сломалось — чините вы
- Нет панели с аналитикой, если сами её не попросите
- Оплата зарубежных моделей — через посредников

**Кому советовать:** «Уже есть поток заявок, хочу свою логику и на вырост».

| | Готовый сервис | Вайб-кодинг |

| Нужен сервер | Нет | Да |
| Вход | 0 ₽ | 0 ₽ |
| В месяц | 1 500–5 000 ₽ | 800–2 500 ₽ |
| Гибкость | В рамках платформы | Любая |

| Если сломалось | Поддержка сервиса | Чините сами |

**Фраза для перехода к своему офферу:**
> «Начинать почти всем стоит с сервиса: потратили вечер, поняли, работает ли это
> в вашей нише. К вайб-кодингу переходят, когда упёрлись в потолок платформы
> или когда счёт за диалоги стал больше, чем сервер.»

## 6. Пять вещей, которые отличают рабочего бота от позорного

Работает одинаково на обоих путях:

1. **База знаний вместо фантазии.** Прайс, условия, гарантии, FAQ, кейсы.
   Всего, чего в базе нет, бот не выдумывает — фиксирует вопрос и зовёт человека.
2. **Явные границы.** Не называть сроки вне прайса, не давать скидки,
   не подтверждать наличие, не обсуждать конкурентов.
3. **Точка передачи человеку.** Не «когда сложно», а по триггерам: просят менеджера,
   спор о цене, жалоба, третий повтор одного вопроса.
4. **Скрипты от вашего лучшего менеджера.** Его 20–30 переписок уже лежат в CRM бесплатно.
5. **Замер до внедрения.** Без цифр «до» эффект «после» не с чем сравнить.

> «Причина 90% плохих ботов одна: их запустили без базы знаний и без границ.
> Бот не тупой — ему просто не сказали, что можно, а что нельзя.»

## 7. Каркас системного промпта (общий для обоих путей)

```
РОЛЬ
Ты — менеджер по продажам компании [НАЗВАНИЕ]. Общаешься в переписке,
коротко и по-человечески. Не более 4 предложений в сообщении.

ЦЕЛЬ ДИАЛОГА
[Записать на разбор / собрать контакт / довести до оплаты]

БАЗА ЗНАНИЙ
[Прайс, условия, сроки, гарантии, частые вопросы, кейсы]

ПОРЯДОК РАБОТЫ
1. Поздоровайся и спроси, какая задача
2. Уточни объём, сроки, бюджет — по одному вопросу за сообщение
3. Предложи решение из базы знаний
4. Предложи следующий шаг
5. Возьми контакт и передай менеджеру

ЗАПРЕЩЕНО
— выдумывать цены, сроки и условия, которых нет в базе знаний
— обещать скидки и индивидуальные условия
— обсуждать конкурентов
— задавать больше одного вопроса в сообщении
— писать длинные простыни текста

ЕСЛИ НЕ ЗНАЕШЬ ОТВЕТА
Скажи «Хороший вопрос — уточню у коллеги и вернусь с ответом»
и передай диалог менеджеру.

ПОЗВАТЬ ЧЕЛОВЕКА, ЕСЛИ
— клиент просит менеджера
— клиент недоволен
— начался спор о цене
— клиент третий раз повторяет один и тот же вопрос
```

## 8. Живое демо бота — три сообщения, подготовить заранее

1. **Обычный вопрос** — «Сколько стоит?» → бот отвечает по базе, задаёт встречный вопрос
2. **Возражение** — «Дорого» → бот не оправдывается, а уточняет задачу и показывает ценность
3. **Вопрос вне базы** — «А вы работаете с Казахстаном?» → бот честно передаёт человеку

Третий важнее первых двух: он закрывает главный страх зала — «а вдруг он наврёт клиенту».

## 9. Ответы на вопросы, которые точно прилетят в чат

**«Клиент поймёт, что это бот?»**
> Часто да, и это нормально. Мы не прячем. Людей волнует не кто отвечает,
> а как быстро и по делу. Раздражает не бот — раздражает бесполезный бот.

**«А если он наврёт?»**
> Отвечает только по базе знаний, на остальное — «зафиксирую и передам коллеге».
> Плюс жёсткие запреты по ценам и срокам. Сейчас покажу в демо.

**«Сколько стоит содержание?»**
> Сервис — 1500–5000 ₽/мес. Свой бот — 300–500 ₽ сервер плюс 500–2000 ₽ за модель.

**«Можно без зарубежных моделей?»**
> Да: GigaChat и YandexGPT, оплата картой РФ. Качество ниже топовых,
> для типовых диалогов хватает.

**«Я не программист, вайб-кодинг точно осилю?»**
> Код пишет нейросеть. От вас — описать задачу словами и копировать ошибки
> в чат целиком. Сложнее не программирование, а первая настройка сервера,
> и её тоже проходят вместе с моделью по шагам.

**«У меня 10 заявок в месяц, мне надо?»**
> Скорее нет. При таком потоке дешевле отвечать самому. Бот окупается,
> когда рутина съедает время или заявки идут вне рабочих часов.
